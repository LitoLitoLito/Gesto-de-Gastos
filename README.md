# 📱 Gestor de Gastos (React Native)

Aplicación móvil desarrollada en **React Native** (con Expo) para el control y seguimiento de finanzas personales, permitiendo registrar, clasificar, filtrar y persistir gastos de forma local.

---

## 🚀 Características principales
* **Registro de Gastos:** Permite ingresar descripción, monto y categorización rápida.
* **Categorías:** Alimentación, Transporte, Entretenimiento, Salud y Otros.
* **Persistencia de Datos:** Almacenamiento local mediante `AsyncStorage` para no perder la información al cerrar la app.
* **Filtros dinámicos:** Visualización de todos los gastos o filtrados por categoría específica.
* **Resumen financiero:** Cálculo automático del total gastado, cantidad de transacciones y detección del gasto más alto.
* **Formateo de moneda:** Visualización amigable adaptada al formato de pesos.

---

## 🛠️ Tecnologías utilizadas
* **React Native** / **Expo**
* **React Hooks** (`useState`, `useEffect`)
* **AsyncStorage** para persistencia local.
* **JavaScript (ES6+)**
